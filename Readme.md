# ✨ My To-Do List

> **A modern and responsive productivity web application for managing daily tasks efficiently.**

---

## 🌟 About The Project

**My To-Do List** is a modern web-based task management application developed using **HTML5, CSS3, and JavaScript**.

The application allows users to easily add, complete, and delete tasks while providing a visual overview of their productivity through **task statistics and a dynamic progress bar**.

The interface is designed with a clean, modern, and responsive UI that works across desktop and mobile devices.

---

## 🎨 Features

| Feature            | Description                                |
| ------------------ | ------------------------------------------ |
| ➕ Add Task         | Add new tasks to your daily list           |
| ⌨️ Enter Support   | Press Enter to quickly add a task          |
| ✅ Complete Task    | Mark tasks as completed                    |
| 🗑️ Delete Task    | Remove unwanted tasks                      |
| 🧹 Clear Completed | Remove all completed tasks                 |
| 📊 Task Statistics | View total, completed, and remaining tasks |
| 📈 Progress Bar    | Track your task completion percentage      |
| 📅 Current Date    | Displays the current date                  |
| 📱 Responsive UI   | Works on desktop, tablet, and mobile       |
| ✨ Modern Design    | Gradient background and animated UI        |

## 🖥️ How It Works

### ➕ Add a Task

Enter your task in the input field:

```text
What do you need to accomplish?
```

Then click:

```text
+ Add Task
```

The task will appear in the task list.

### ✅ Complete a Task

Click the circular check button beside a task.

The task will be marked as completed and the statistics will automatically update.

### 🗑️ Delete a Task

Click the trash icon to permanently remove a task.

### 📊 Track Progress

The application automatically calculates:

```text
Total Tasks
     ↓
Completed Tasks
     ↓
Remaining Tasks
     ↓
Completion Percentage
```

The progress bar changes according to the percentage of completed tasks.
